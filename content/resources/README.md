# Resource content

These are plain Markdown files. Each one is shown as a sheet that slides up over
a question when someone taps its link.

- **Edit them in place.** Open the file, change the words, save.
- There is no build step beyond redeploying the site.
- Which file belongs to which resource, and whether a resource is reading, a list
  of links, or an exercise, is set in `content/resources.json`.
- Phone numbers and links live in `content/resources.json`, not here. The
  national hotline numbers live in `src/constants/safety.ts`.
- Lines like `<!-- TODO: clinician content -->` are invisible notes. Delete them
  once the real content is written.
